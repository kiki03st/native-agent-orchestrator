# 서버 기동 직후 사례 검색 타임아웃 수정

## 증상

서버를 띄운 직후 `ai.kb.search.search_cases` 호출이 동시에 5건 들어오면 검색 예산 1초를 넘겨 5건 모두 타임아웃된다.
먼저 한 건이 끝난 뒤에는 동시 20건도 정상이다.

## Task 1: 원인을 찾아 고치기

- 원인을 코드에서 직접 확인한다.
- 동시에 들어온 첫 호출들도 정상적으로 예산 안에 끝나야 한다.
- `load_cases()`처럼 기본 경로로 부른 호출과 `load_cases(CASES_DIR)`처럼 같은 경로를 명시한 호출은 같은 결과 객체를 공유해야 한다.
- 필요한 회귀 테스트를 추가한다.
- 검증: 저장소 루트에서 `python -m pytest tests -q`
